# 闭店巡检台 · 水族店

打烊前逐缸巡检、危险项处置闭环与按班次交班记录。

## 技术栈

React + Vite + TypeScript + CSS，数据保存在浏览器 localStorage。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5105

## 功能

- **巡检录入**：每缸登记 pH、氨氮（mg/L）、温度（℃）和换水量，按班次（日期 + 早/中/晚班）自动保存草稿，关掉页面不丢失
- **危险判定**：氨氮 ≥ 0.5 mg/L、温度 < 22℃ 或 > 30℃、pH < 6 或 > 8.5 即标危险
- **处置闭环**：危险项须填写处置人和处置说明并点「完结」；完结后改动对应读数，处置自动失效需重新完结
- **提交拦截**：存在未测鱼缸或未完结危险项时无法提交闭店结果，并逐条列出具体鱼缸与缺失项
- **交班记录**：提交后生成当班记录，含各缸读数与每项危险的处置人、说明、完结时间，按日期/班次查看，刷新或重开页面仍在
- **班次锁定**：已提交的班次内容锁定，避免事后改动
