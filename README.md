# 闭店巡检台（水族店打烊巡检）

打烊前逐缸巡检、危险项处置与按班次留档的闭店工具。

## 技术栈

React + Vite + TypeScript + CSS，数据保存在浏览器 localStorage（关页面不丢失）。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5105

## 功能

- 开班后逐缸登记 pH、氨氮（mg/L）、温度（℃）、换水量（%）
- 危险判定：氨氮 ≥ 0.5、温度超出 22~30℃、pH 超出 6~8.5，超标字段即时标红
- 危险项必须填写处置人和处置说明并点击「完结此项」，处置过程带时间线留痕
- 存在未测鱼缸或未完结危险项时禁止提交闭店，并逐条列出具体鱼缸和缺失项
- 交班记录按班次归档，关掉页面后仍可在「交班记录」中查看各缸数据、处置过程和交班备注
